# Producción y publicación

Esta lista acompaña al episodio desde la preparación hasta el archivo posterior a la publicación. Adáptala al medio final cuando el formato esté definido.

## Preproducción

- [ ] La versión aprobada está enlazada en la ficha del episodio.
- [ ] Están confirmados participantes, permisos y disponibilidad.
- [ ] Las necesidades técnicas y de locación están documentadas.
- [ ] Existe una lista de recursos: audio, video, imágenes, textos, música o archivos.
- [ ] Están asignados responsables y fechas.
- [ ] Se conoce el formato de entrega y el destino de publicación.
- [ ] Existe un plan alternativo para los elementos críticos.

## Producción

- [ ] Se registró la fecha, versión y responsable de cada captura.
- [ ] Los archivos originales se conservaron sin sobrescribirlos.
- [ ] Las tomas o fuentes importantes tienen notas de contexto.
- [ ] Se registraron incidentes, cambios y decisiones tomadas en el momento.
- [ ] Se confirmó qué material tiene restricciones de uso.

## Postproducción

- [ ] La edición cumple la promesa y la estructura del episodio.
- [ ] Se revisaron hechos, nombres, fechas y continuidad.
- [ ] Se eliminaron errores técnicos y silencios no intencionales.
- [ ] Se revisaron audio, imagen, color, legibilidad y ritmo.
- [ ] Se prepararon subtítulos, transcripción o texto alternativo cuando corresponda.
- [ ] Se añadieron créditos, fuentes, permisos y advertencias necesarias.
- [ ] Dos personas distintas revisaron el corte final cuando sea posible.

## Paquete de publicación

Cada episodio debe salir acompañado de:

- archivo final;
- título y descripción;
- imagen o miniatura, si aplica;
- créditos y fuentes;
- transcripción o subtítulos, si aplica;
- enlaces relacionados;
- fecha, versión y responsable;
- notas de cambios frente a la versión anterior.

## Después de publicar

- [ ] Se verificó la publicación en el destino real.
- [ ] Los enlaces y archivos descargables funcionan.
- [ ] Se archivó el paquete final junto con su ficha.
- [ ] Se registraron correcciones o comentarios recibidos.
- [ ] Se agendó una retrospectiva breve.

## Convención de nombres

Usa nombres legibles y estables, por ejemplo:

```text
E01_nombre-corto/
  E01_guion_v01.md
  E01_audio_original_2026-10-10.wav
  E01_corte_v03.mp4
  E01_publicacion_final.md
```

No uses `final-final-ahora-si`. El número de versión y el estado deben decir cuál archivo es vigente.
