# Temporalmente Humilde

Espacio de desarrollo para una serie en construcción. Este repositorio reúne la biblia del proyecto, los flujos de trabajo y las plantillas necesarias para pasar de una idea a un episodio terminado.

El material está escrito para funcionar como base tanto para una serie audiovisual como para un podcast o una publicación episódica. Las decisiones específicas del formato y del canon se registran en [`docs/decisiones-pendientes.md`](docs/decisiones-pendientes.md) antes de convertirlas en reglas permanentes.

## Cómo trabajar aquí

1. Copia [`templates/episodio.md`](templates/episodio.md) para iniciar un episodio.
2. Sigue el flujo de [`docs/01-flujo-creacion-de-episodios.md`](docs/01-flujo-creacion-de-episodios.md).
3. Registra las decisiones que afecten a personajes, mundo o continuidad en [`docs/02-biblia-y-continuidad.md`](docs/02-biblia-y-continuidad.md).
4. Antes de publicar, completa la lista de [`docs/03-produccion-y-publicacion.md`](docs/03-produccion-y-publicacion.md).

## Principios de la serie

Hasta que la sala de desarrollo los precise, el proyecto se guía por estos principios:

- La humildad es una práctica, no una pose.
- Cada episodio debe tener una pregunta, un cambio y un cierre reconocible.
- La experiencia humana importa más que la explicación del concepto.
- La continuidad ayuda a contar mejores historias; no debe impedir experimentar.
- Toda versión se etiqueta y se archiva para que las decisiones sean reversibles.

## Estado actual

Este repositorio contiene el kit inicial de desarrollo. El tono, el formato, la duración, la audiencia, los personajes y el calendario de publicación siguen abiertos y deben acordarse en la biblia del proyecto.
